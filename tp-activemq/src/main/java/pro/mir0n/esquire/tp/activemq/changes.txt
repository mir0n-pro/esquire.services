06/15/2026 mir0n  v1.2.8 -- ActiveMQ transport provider module
tp.activemq.TransportProvider  (new)
  - ActiveMQ implementation of the transport-provider SPI; resolved by name (reflectively instantiated,
    no Spring bean) and owns its own audit broker connection.
  - openPublisher builds its own JmsTemplate over a CachingConnectionFactory (poolSize>0 -> useAsyncSend
    plus sessionCacheSize); send() stamps appl-msg-id + sending-time and writes the header bag via
    messaging.jms.Utils.setProps.
  - openConsumer runs a programmatic DefaultMessageListenerContainer (selector, concurrency, topic/queue
    from settings) lifting every JMS property into a neutral TransportMessage header map.
  - withParams appends the leg's transport.params verbatim to the broker URI; readProps lifts all JMS
    properties into the header map.
tp.activemq.TpActiveMqAutoConfigFilter  (new)
  - AutoConfigurationImportFilter suppressing Boot's ActiveMQAutoConfiguration + JmsAutoConfiguration so a
    service that ships this provider stays transport-agnostic.
pom.xml  (new)
  - esquire-tp-activemq module; depends on esquire-common + spring-boot-starter-activemq.
META-INF/spring.factories  (new)
  - registers TpActiveMqAutoConfigFilter as an AutoConfigurationImportFilter.
