05/22/2026 mir0n  v1.2.5 Taijitu -- synchronous command model + IMonad control contract
taijitu.IMonad  (new)
  - the monad CONTROL contract a director drives: start/shutdown, offer, setQueueEnabled/
    setProcessingEnabled/queueClear, status/queueSize/id, setCmdResponseListener,
    doCommand(String cmd, boolean enableQueue, long timeoutMs). AMonadY implements it
taijitu.AMonadY
  - implements IMonad; public control methods renamed to the IMonad names: stop()->shutdown(),
    clearQueue()->queueClear(), queueDepth()->queueSize(), monadId()->id() (submit() stays, used
    internally by doCommand -- not on the interface)
  - added doCommand(cmd, enableQueue, timeoutMs): posts the command, opens the queue right after
    (when enableQueue), BLOCKS on an inner CommandGate monitor until the worker signals; timeoutMs<=0
    waits indefinitely, a positive timeout cancels the registered cancelable + grace-waits; returns
    the result string (status name / "TIMEDOUT" / "INTERRUPTED")
  - new inner CommandGate implements ICmdResponseListener: holds result + cancelable; the worker
    notifies it (onStarted/onResult), it forwards to the rig listener and notifies doCommand
  - handleCommand notifies via the gate; CLEAR wrapped in try/finally -> always IDLE + onResult
  - listener field renamed cmdResponseListener -> rigCmdResponseListener
  - instance loggers via getClass() (was static AMonadY.class)
taijitu.ATaijituRigY
  - bootstrap() renamed start(); active monad held as AtomicReference<IMonad>
  - ctor registers the director as the monad's ICmdResponseListener (yang.setCmdResponseListener(this))
  - start() is a synchronous retry loop: clearMonad(active) then doCommand(LOAD, true, 0) until
    LOADED, else sleep(retryDelayMs) + retry
  - added clearMonad(IMonad): setQueueEnabled(false) + queueClear() + setProcessingEnabled(true) +
    doCommand(CLEAR, false, 0)
  - onStarted/onResult drive the per-command gate-flag policy (LOAD: processing off during load,
    on at LOADED; FAILED / CLEAR: queue + processing off)
  - instance loggers via getClass()
taijitu.ITaijituRig
  - bootstrap() renamed start()
taijitu.MonadStatus
  - each constant carries a String code; added code() accessor

05/21/2026 mir0n  v1.2.5 Taijitu Step 3 generalization -- queue rig + monad framework lifted from bizTree
concurrent.IQueueRig  (new)
  - generic active-object queue contract <E>: bounded FIFO drained by one worker (IQueueWorker);
    processing gate (setProcessing -- when false the worker leaves the queue UNTOUCHED, no dequeue);
    put / size / clear; nested IErrorListener<E> seam
concurrent.BoundedQueueRig  (new)
  - implements IQueueRig<E>: ArrayBlockingQueue + single daemon worker; gate parks before dequeue;
    recoverable Throwable -> IErrorListener and the worker keeps running; Error propagates;
    InterruptedException = shutdown; clear() bulk-drops. Lifted from bizTree MonadY
taijitu.QueueItem  (new)
  - flat record(eventType, entityId, entityKind, requestId, correlationId, messageEncoding, text);
    commands and events share the one record; a command is eventType==MonadCmd.CMD with
    entityId=the command id -- no sealed hierarchy
taijitu.MonadCmd  (new)
  - final class; interned String command vocabulary: CMD (eventType marker), LOAD, CLEAR, CHECKSUM
taijitu.MonadStatus  (new)
  - enum IDLE / LOADING / LOADED / FAILED
taijitu.AMonadY  (new)
  - abstract cache monad: owns a BoundedQueueRig over QueueItem, the status machine, two gates,
    and command EXECUTION (LOAD/CLEAR/CHECKSUM); single abstract hook _processItem(QueueItem);
    fires onStarted/onResult; only LOAD/CLEAR change status, message/CHECKSUM faults traced by the rig
taijitu.ATaijituRigY  (new)
  - abstract director: implements ITaijituRig + ICmdResponseListener; holds the active AMonadY;
    bootstrap (submit LOAD, enable queue + processing); DRIVES the processing gate off the monad
    callbacks (onStarted LOAD -> processing off; onResult LOADED -> on; FAILED -> setQueueEnabled(false)+clearQueue)
taijitu.ITaijituRig  (new)
  - director contract: bootstrap() / onEntityBroadcast(7 raw fields) / shutdown(); bean-blind, REST-free
taijitu.ICmdResponseListener  (new)
  - onStarted(commandId, ICancelable) + onResult(commandId, MonadStatus); NOOP default
taijitu.ICancelable  (new)
  - in-flight command abort handle: cancel()
